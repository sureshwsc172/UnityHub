# Unity 3D Model Hub

A free, public webpage listing free Unity 3D model resources, with an email-based
submission/discussion link.

## Deploy steps (free, no coding needed after this)

1. Create a free GitHub account at https://github.com (skip if you have one).
2. Create a new repository (e.g. "unity-3d-model-hub") — keep it Public.
3. Upload every file in this folder to that repository
   (GitHub's web UI: "Add file" → "Upload files" → drag all files/folders in, then Commit).
4. Go to https://vercel.com and sign up with your GitHub account (free).
5. Click "Add New Project", select your unity-3d-model-hub repo, click Deploy.
6. Vercel builds it automatically and gives you a live public URL
   like unity-3d-model-hub.vercel.app — share that with anyone.

## Making future changes

Just tell Claude what to change. Claude will give you the updated file(s) —
replace them in your GitHub repo (or ask Claude to regenerate the whole project),
and Vercel redeploys automatically within about a minute of any GitHub update.
